Ces projets ont été réalisés dans le cadre de mes cours en Licence 1 Informatique.
Il s'agit de mes tout premiers projets informatiques, destinés à apprendre les bases de la programmation, la manipulation de fichiers et de dictionnaires, ainsi que la logique de correction et traduction de mots.

Projet 1 : Traducteur

Objectif : traduire des mots selon un dictionnaire fourni.

On nous a donné un dictionnaire contenant des mots et leurs traductions, que le programme utilise pour traduire les entrées de l’utilisateur.

Ce projet permet de découvrir la lecture de fichiers, l’association clé-valeur et les premières fonctions de manipulation de chaînes.

Projet 2 : Correcteur

Objectif : corriger l’orthographe de mots selon un dictionnaire.

On nous a fourni un dictionnaire complet, et le programme doit identifier les mots incorrects et proposer des corrections.

Ce projet permet de se familiariser avec les structures de données, les boucles et les algorithmes simples de correction.
